Playground

Three settings, one cloud. density and fillFactor interact, which is easier to feel than to read about: raise fill factor to 1 and density stops appearing to do anything, because the layout grows the type to absorb whatever space tighter packing just freed up. Pull fill factor down and the same density changes become obvious.

Words never overlap at any combination, and the layout is deterministic — the same three values always produce the same cloud.

0.50

How tightly words cluster. 0 spreads them evenly, 1 packs them around the centre and leaves the corners empty. Default 0.5.

0.60

How much of the box to claim. 1 grows the type until the cloud fills it — when crowded the ramp can outgrow the box and a word spills past the edge, by design. 0 keeps the authored size. The library default is 0.75; this demo starts at 0.6 so density stays visible.

30

How many words to pack. Tags that survive a change keep their position, so adding and removing words animates rather than reshuffling.
